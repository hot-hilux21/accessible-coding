# Privacy policy

Jojo Code is offline-first. On the Windows app your code runs on your own computer and nothing is uploaded. The browser copy sends your code to the server to run it and returns the output; that code is not stored beyond the run. No accounts are created, no personal data is collected, and there are no analytics. The only network request the app makes on its own is the optional update check, which can be turned off in Settings. The hosted site is served from Oracle Cloud. Code signing is provided by the SignPath Foundation.
