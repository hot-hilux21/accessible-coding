# Frequently Asked Questions

## Is my code private?
On the Windows app, yes: code runs on your computer. On the browser version, code is sent to the server to run, then the output is sent back.

## Which fonts help with dyslexia?
There is no single best font. Try OpenDyslexic, Atkinson Hyperlegible, Lexend, Nunito, Andika, or your own font, and keep the one that feels easiest to read.

## Can I use my own font?
Yes. Upload a `.ttf`, `.otf`, `.woff`, or `.woff2` file in Settings.

## How do I change the language?
Open Settings, choose Language, or use the first-run setup screen.

## How do I report a problem?
Use the feedback form in Settings, or open an issue on GitHub.

## Is the app free?
Yes. Jojo Code is free and open source.
