# Accessibility statement and testing approach

Jojo Code targets WCAG 2.1 AA and selected WCAG 2.2 additions.

## Current evidence

- Automated contrast tests exist for bundled and derived themes.
- DOM harness covers setup, settings, pane toolbars, glossaries, keyboard, sounds, updates, and run controls.

## Outstanding evidence

- Full criterion-by-criterion WCAG 2.2 AA matrix.
- Complete keyboard, screen-reader, zoom, reflow, forced-colour, and editor interaction testing.
- Real assistive-technology user testing.

Known limitations should be recorded in the accessibility conformance matrix before broad accessibility claims are made.
